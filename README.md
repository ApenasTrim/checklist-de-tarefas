***English:***

Code for creating a task list with PySimpleGUI using an expandable layout with checkboxes and text fields. If the "Nova Tarefa" button is clicked, the system dynamically injects new elements into the screen in real-time, and if the "Formatar" button is triggered, the window resets to clear the checklist.

Requirements: To run this project, you need to have the PySimpleGUI library installed. You can install it using pip:

pip install PySimpleGUI

***Português:***

Código para criar uma lista de tarefas com PySimpleGUI usando um layout expansível com checkboxes e campos de texto. Se o botão "Nova Tarefa" for clicado, o sistema injeta dinamicamente novos elements na tela em tempo real, e se o botão "Formatar" for acionado, a janela é reiniciada para limpar o checklist.

Requisitos: Para rodar este projeto, é necessário ter a biblioteca PySimpleGUI instalada. Você pode instalá-la usando o pip:
